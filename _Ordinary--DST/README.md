# 普通系列 · 0.2.1

从普通的东西开始。前三个头部物品使用原版普通帽下显隐规则；普通头环使用OPEN规则保留普通头型与头发，均无护甲、理智、保暖、隔热、防水或特殊能力，不消耗耐久，不可堆叠。

| 物品 | 外观 | 无科技配方 | Prefab |
|---|---|---|---|
| 破帽基 | 只有实面 | 草 ×2 | roomcar_tattered_hat_base |
| 破帽网 | 只有网面 | 草 ×2 | roomcar_tattered_hat_mesh |
| 破帽子 | 实面在下、网面在上 | 破帽基 ×1 + 破帽网 ×1 | roomcar_tattered_hat |
| 普通头环 | 完整编绳、正面同色小结 | 绳索 ×1 | roomcar_plain_circlet |

制作栏：服装。支持拾取、掉落、交易、漂浮、装备、卸下及原生物品存读档。界面名称和检查文字跟随中英文语言。

把本目录复制到饥荒联机版的 mods/roomcar_ordinary_dev，在本地世界启用“普通系列”。所有联机客户端均需启用。

美术源文件与可重建的制作入口分别在仓库 assets/ordinary_series/ 和 tools/ordinary_series/。

普通头环测试命令：`c_give("roomcar_plain_circlet")`。
