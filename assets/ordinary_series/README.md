# 普通系列源素材

mesh.webp 和 solid.webp 是已确认“破帽子”的两张独立透明图层，每张2172×724，依次为正、侧、背。保留已确认的整体缩放、平移和画风；不包含逐行拉伸。

registration.json 记录这些画布与原生待机 swap_hat 挂点的关系。构建时反算每个方向的符号坐标，背面保留原生镜像与小角度旋转；不会把已经合成过的待机变换重复应用。

完整帽子的像素叠放顺序：先 solid，再 mesh。仅帽基和仅帽网也采用同一套普通帽下显隐规则。

## 普通头环

circlet.webp 为70% OPEN覆盖区域参考下的编绳头环，三视图仅做整体轴向缩放和平移。内部编织开孔保持真实透明；不逐行扭曲、填孔或把透明度强制设为255。与三顶帽子共用挂点记录，但佩戴采用OPEN规则保留HEAD、HAIR、HAIR_NOHAT。
